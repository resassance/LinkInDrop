LinkInDrop связывает устройства на Android, Windows и Linux для передачи файлов и общего буфера обмена. Привяжите устройства, выберите получателя, проверьте список файлов и отправьте их. Для соединения подойдут локальная сеть, общая частная VPN-сеть или собственный ретранслятор для доступа на расстоянии.

**Предварительная версия.** В `0.3.0-alpha.4` изменены идентификатор приложения и протокол подключения. Установите новую версию на все устройства и заново свяжите их. Прежнее приложение и его внутренние данные хранятся отдельно; сохраните полученные файлы перед его удалением. Для передачи и просмотра оба устройства должны быть включены, а приложение — запущено.

## Возможности

| Возможность | Как работает |
| --- | --- |
| Файлы и папки | Выбор через диалог, перетаскивание на ПК или меню «Поделиться» на Android. Перед отправкой видны миниатюры фото и список документов. |
| Удалённый просмотр | Просмотр выбранных для общего доступа файлов и папок: поиск, предпросмотр, скачивание и избранные папки. |
| Общий буфер | Передача текста и изображений. Автоматический обмен включается отдельно. |
| Очередь передач | Пауза, продолжение, повтор, приоритеты, скорость и оставшееся время. Продолжение с проверенных блоков файла. |
| Полученные файлы | Быстрое открытие папки получения и необязательная сортировка отдельных файлов по типам. Структура переданных папок сохраняется. |
| Фотобэкап | Копирование новых фото из выбранных папок, проверка копий и восстановление. Бэкап можно отключить; оригиналы остаются на исходном устройстве. |
| Фоновая работа | Трей на ПК; на Android — включаемая служба с уведомлением, исключение из оптимизации батареи и необязательный запуск после перезагрузки. |
| Оформление | Компактные экраны для ПК и телефона, светлая, тёмная и системная темы; русский, английский и язык системы. |

## Установка

Пакеты и контрольные суммы SHA-256 доступны в [релизах](https://github.com/resassance/LinkInDrop/releases).

| Платформа | Пакет | Запуск |
| --- | --- | --- |
| Windows x64 | `linkindrop-*-windows-x64.zip` | Распакуйте архив целиком и запустите `LinkInDrop.exe`. |
| Linux x64 | `linkindrop-*-linux-x64.tar.gz` | Распакуйте и запустите `LinkInDrop/LinkInDrop`. Нужны GTK 3 и поддержка AppIndicator в окружении рабочего стола. |
| Android 6+ | `linkindrop-*-android.apk` | Установите APK, разрешив установку из приложения, через которое скачан файл. |

В Debian/Ubuntu для Linux нужны, в частности, `libgtk-3-0` и `libayatana-appindicator3-1`; названия пакетов зависят от дистрибутива. Перед публикацией подпись APK проверяется по постоянному сертификату проекта.

## Подключение и передача

1. Откройте LinkInDrop на обоих устройствах. Они должны иметь возможность обратиться друг к другу по сети.
2. Нажмите **«Добавить устройство»**. На втором устройстве отсканируйте QR-код или введите код подключения.
3. Подтвердите запрос. Приглашение действует пять минут.
4. Выберите получателя, добавьте файлы или папку, проверьте список и нажмите **«Передать»**.
5. Для просмотра включите общий доступ на нужном устройстве и выберите доступные файлы или папки. На другом устройстве откройте **«Файлы устройства»**.

На Windows при необходимости нажмите **«Разрешить локальные подключения»**. После подтверждения администратора создаются правила входящих подключений для приложения из локальной подсети. Порты по умолчанию: TCP `45831` и UDP `45832`; фактический порт может отличаться. Гостевая Wi-Fi-сеть и изоляция клиентов могут мешать подключению.

## Удалённый доступ и VPN

Для соединения через интернет настройте общий собственный ретранслятор или объедините устройства частной сетью, например Tailscale, и укажите удалённый адрес. См. [развёртывание ретранслятора](relay_server/README.md). Готового публичного сервера в комплекте нет.

**NekoBox на Android:** разрешите обход локальной сети или исключите `dev.resassance.linkindrop` из маршрутизации приложений через VPN. Необязательный режим прямого Wi-Fi направляет весь трафик LinkInDrop через физическую Wi-Fi/Ethernet-сеть, пока она доступна, и возвращает системный маршрут после её потери. Маршруты других приложений не меняются. Блокировка соединений без VPN в Android или запрет обхода в VPN-приложении всё ещё могут препятствовать соединению.

Фоновую работу на Android нужно включить явно. Уведомления и исключение из оптимизации батареи помогают сохранять соединение, но ограничения производителя и принудительная остановка могут прервать его. У фотобэкапа есть отдельный переключатель.

## Данные и разрешения

- Соединение устройств использует TLS с закреплёнными сертификатами и токенами доступа. Привязка требует подтверждения.
- Удалённо видны выбранные файлы и папки. Доступ можно ограничить отдельными устройствами, задать срок и отозвать.
- Ретранслятор передаёт зашифрованное соединение без расшифровки содержимого. Оператору доступны метаданные подключения и объём трафика.
- Полученные файлы сохраняются в выбранной папке. Новые файлы и изменения внутри общей папки могут быть видны, пока действует разрешение на неё.

## Сборка из исходников

Нужны Flutter **3.32.8**, Python 3 и инструменты выбранной платформы. Для Android — Java 17 и Android SDK; для Windows — средства разработки настольных приложений C++ в Visual Studio; для Linux — Clang, CMake, Ninja и заголовки GTK/AppIndicator.

```sh
git clone https://github.com/resassance/LinkInDrop.git
cd LinkInDrop
python tool/bootstrap.py
flutter pub get
flutter run
```

Проверки:

```sh
python tool/check_design.py
python -m unittest tool/bootstrap_test.py tool/signing_test.py
npm install --prefix relay_server
npm test --prefix relay_server
flutter analyze --no-fatal-infos
flutter test --timeout 2m
```

Соберите приложение командой `flutter build windows --release`, `flutter build linux --release` или `flutter build apk --release`. Затем запустите `python tool/package.py windows`, `linux` или `android`: пакеты и контрольные суммы появятся в `dist/`. Без реквизитов постоянного ключа локальная Android-сборка использует подпись для разработки; официальные APK подписываются ключом проекта.
